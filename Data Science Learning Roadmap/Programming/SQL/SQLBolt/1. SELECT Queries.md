# 101
To retrieve info from a database using SQL, we need to write `SELECT` statements, which are also known as _queries_. 

When using SQL, it's good to know that we can think of the tabular data used (e.g., two-dimensional data-frames) as entities (e.g., dog), the rows as instances (e.g., pug, beagle, etc), and the columns as common properties shared by them (e.g., bark level, furry level, color of fur).

The most basic query we can do is select columns from our data:
```
SELECT column, another_column, ...
FROM mytable;
```

If we want to retrieve absolutely all the columns of data from a table, we can then use the asterisk (`*`) shorthand in place of listing all the column names individually.

```
SELECT *
FROM mytable;
```

# Queries with conditions

Selecting columns just from our own manual search can be a lot of work especially if there is a lot of properties and rows. We can implement conditions to constrain the search so its less burdened.

```
SELECT column, another_column, … 
FROM mytable 
WHERE condition 
	AND/OR another_condition 
	AND/OR …;
```

Making sure to not put the semicolon until the **end** of the query. We can use keywords in the `WHERE` condition like =, !=, (using "" for string matching), `LIKE` for approximate string matching with the '%', `IN` or `NOT IN` if its in a list.

# Filtering and Sorting Query Results

If we want to get unique results, we need to use the keyword `DISTINCT` after the `SELECT`. Eventually we can be more specific as to which rows we want removed rather than this blind filtering. 

After the `WHERE` clause, we can put an `ORDER BY` clause to specify based on the condition therein. 

Note that if we want to search for a particular row value, we use apostrophe marks instead of quotation, where rows are for the former and columns are for the latter.

We can limit the results to a subset amount by using the LIMIT and OFFSET keywords alongside the `ORDER BY` clause. `LIMIT` reduces the number of rows to return, and the optional `OFFSET` specifies where to begin counting the rows from.
