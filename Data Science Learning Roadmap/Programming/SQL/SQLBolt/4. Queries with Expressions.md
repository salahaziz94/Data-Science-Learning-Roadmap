We can make more complex queries by changing up the specifications of the searched column, as well as the `WHERE` condition. 

```
#example 

SELECT particle_speed / 2.0 AS half_particle_speed 
FROM physics_data 
WHERE ABS(particle_position) * 10.0 > 500;
```

In the above, the column is newly generated as "half_particle speed".

We can also make an alias for the table after the `FROM` keyword as long as we use the `AS` keyword as before.

# Queries with Aggregates

SQL also supports the use of aggregate expressions (or functions) that allow you to summarize information about a group of rows of data. With the Pixar database that you've been using, aggregate functions can be used to answer questions like, "How many movies has Pixar produced?", or "What is the highest grossing Pixar film each year?".

We can put the aggregate function just after the `SELECT` keyword. We can specify this as anything we need, and also make an alias using AS like before. We can also, use the `GROUP BY` keyword to group all the particular rows in question together at the end.

```
SELECT AVG(Years_employed) as yr_avg
FROM work_database
WHERE condition...
GROUP BY role
```

Some aggregate functions:

COUNT(*), COUNT(column) A common function used to counts the number of rows in the group if no column name is specified. Otherwise, count the number of rows in the group with non-NULL values in the specified column.
MIN(column) Finds the smallest numerical value in the specified column for all rows in the group.
MAX(column) Finds the largest numerical value in the specified column for all rows in the group.
AVG(column) Finds the average numerical value in the specified column for all rows in the group.
SUM(column) Finds the sum of all numerical values in the specified column for the rows in the group.

The HAVING keyword is essentially the same as a WHERE keyword, but it is placed after GROUP BY, if there is one. Otherwise, we just use a WHERE.
