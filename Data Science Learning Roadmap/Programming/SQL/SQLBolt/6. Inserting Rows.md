The _Database Schema_, or the structure of the table we are working with, has some rules built in. For instance, the values in the 'Movies' column needs to have string data, and the values in the 'Year' column needs to have integer data. 

When we want to insert rows into our data, we need to use the `INSERT INTO` keyword, and respecting the structure already. Every row we insert needs to have values for every column we have. Multiple rows can be inserted sequentially in a command.

```
INSERT INTO mytable
VALUES (value_or_expr, another_value_or_expr, ...)
       (value_or_expr2, another_value_or_expr2, ...))
```

If we don't have data for all the columns, we can just specify the columns specifically after the `INSERT INTO` keyword. In these cases, the number of values need to match the number of columns specified. 

```
INSERT INTO mytable
(column, another_column, ...)
VALUES (value_or_expr, another_value_or_expr, ...)
       (value_or_expr2, another_value_or_expr2, ...))
```

Note that you actually need the parentheses around the column and values.
